# earth-seasons

地球の傾きと四季 ― 地軸を知る。昼と夜を知る。季節を知る。

地軸・昼夜・四季を、図を動かしながら学べる1ページのサイトです。
JavaScript と SVG / Canvas だけで動作し、外部ライブラリは不要です。
姉妹編：[moon-age-calendar](https://github.com/fmseitai-coder/moon-age-calendar)（月齢カレンダー ― 月を知る、潮を知る）

公開ページ: https://fujitamario.com/molt/earth/

## 内容

- **回せる地球**: NASA の写真を球に貼った地球。ゆっくり自転し、ドラッグで回せる
- **いまの地球**: 今の日時の、昼と夜に分かれた地球
- **① 地軸**: 傾きをスライダーで 0〜90度に変えて、回帰線・極圏・熱帯/温帯/寒帯がどう変わるかを見る
- **② 昼と夜**: 都市と時刻を選んで、日の出・日の入り・昼の長さ・太陽の高さを見る
- **③ 四季**: 日付を動かして、公転と季節、昼の長さ、太陽の高さ、季節のずれ（気温のピークが遅れる理由）を学ぶ

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | スタイル |
| `app.js` | 太陽の位置の計算と、すべての図の描画 |
| `img/earth-oct.jpg` | 地球の写真（2048×1024、等距円筒図法） |

サーバーに置くときは、この4つがあれば動きます。

## 使い方

サーバーに置くか、ローカルサーバーで開いてください。

```
python -m http.server 8124
```

`index.html` をダブルクリックで開くこともできますが、ブラウザの安全のしくみで、写真を球に貼れません。その場合、一番上の地球は、平らな写真が横に流れる簡易表示に切り替わります。

## 精度について

太陽の位置は簡略式による計算で、昼の長さ・日の出・日の入りは数分程度の誤差があります。大気の屈折は考えていません。
グラフの東京の月平均気温は、気象庁の平年値をもとにした目安です。
